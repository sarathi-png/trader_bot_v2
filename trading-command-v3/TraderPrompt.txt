# Port trader_bot_v2 signal intelligence into trading-command-center

## Source (READ ONLY — never edit): D:\Projects\trader_bot_v2
## Target (edit here): C:\tc\trading-command-center
## Stack: Next.js 16 + React 19 + TypeScript + drizzle/postgres + tailwind. Verify with `npm run typecheck` and `npm run build`.

## Goal
Port the proven Python signal-intelligence stack into the Next.js terminal so its Strategy/Signals pages use the same (or better) logic as the Python bot. No Python runtime, no new native deps. Training stays in Python; only inference + diagnostics move to TS.

## Constraints
- Zero new native/binary npm deps. Only pure TS.
- No look-ahead: every feature/indicator at index i reads candles[0..i] only. Add a test asserting this (shift fixture by one bar → output changes only at tail).
- Costs mirror Python: 0.059% fee + 0.02% slippage per side, stop-first fills.
- Keep existing demo/delta market service, paper engine, journal, auth untouched. New code must not break `npm run typecheck` / `npm run build` / `npm run lint`.
- Cross-check rule: pick 200 consecutive demo candles, compute confluence+features in both Python and TS, assert max abs diff < 1e-6. Document the check.

## Definition of done
`npm run typecheck` + `npm run build` pass; new unit tests green; Strategy page quant tab shows live confluence + meta probability on demo and Delta candles; diagnostics panel renders IC/HAC/FDR/DSR/PBO from walkForward.ts.
